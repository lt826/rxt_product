## 一、项目介绍

**融销通**（基于数字经济的农产品融销一体平台）是一个面向**农户、银行、买家（采购商）、专家**四类用户的农业综合服务平台。平台采用 **B/S 架构、SpringBoot + Vue 前后端分离**技术开发，围绕农户生产经营中最痛的两件事——**钱从哪来（融资）** 和 **货卖出去（销售）**，构建"融资 + 销售 + 服务"的一体化生态。

平台核心业务能力包括：

| 模块 | 主要功能 |
| ---- | -------- |
| 融资服务 | 贷款产品浏览、融资申请、联合贷款人邀请、智能匹配（联合贷款人/信誉/金额/期限四因子加权）、银行贷款审批 |
| 农产品交易 | 商品货源发布与查询、求购需求发布与认领、购物车、下单支付、订单管理（发货/收货） |
| 专家助力 | 农业知识库与讨论、在线专家问答、专家线下预约（出诊） |
| 平台管理 | 用户管理与审批、商品管理、数据统计（ECharts 可视化） |
| 通用能力 | 站内私信与系统通知、关注关系（粉丝精准推送）、收货地址管理、文件上传、支付宝支付对接 |

系统角色职责：

- **农户**：发布/购买农产品、申请融资、邀请联合贷款人、咨询专家；
- **银行用户**：发布融资产品、智能匹配农户、审批贷款申请；
- **买家（采购商）**：发布求购需求、批量采购农产品；
- **专家**：管理农业知识、解答在线问答、处理线下预约；
- **管理员**：用户审批与管理、商品审核、平台数据统计。

## 二、当今形势

尽管我国农产品交易逐步向数字化方向转型，但传统单边市场模式仍占较大比重，产销信息不对称，导致市场效率不足、产销对接不畅。近年来，受经济形势、极端天气等不确定因素影响，**农产品滞销、价格波动**等问题更加突出；与此同时，农户群体普遍面临**融资难、融资贵、贷款流程繁琐、抗风险能力弱**等挑战，严重制约了农业产业的可持续发展。

从政策与产业环境看：

- **数字乡村建设**持续推进，农村电商、智慧农业成为乡村振兴的重要抓手；
- **供应链金融**加速下沉，国家多渠道引导金融资源服务"三农"，普惠金融迎来窗口期；
- 农户线上化程度不断提高，直播带货、社区团购等新模式已被广泛接受，**"互联网 + 农业 + 金融"的融合平台正当其时**。

在此背景下，融销通应运而生：深度融合数字技术与农业经济，整合供应链金融、电商销售、智慧农业等服务，助力农户应对市场风险、提升经营效益。

## 三、项目优势

1. **融销一体，破解双侧难题**：将"融资"与"销售"打通在同一平台。农户既能在平台上售卖农产品、对接采购需求，又能便捷地发起融资申请，销售数据反哺信用，形成良性循环。
2. **AI 智能匹配，提高贷款成功率**：通过联合贷款人、信誉分、金额、期限**四因子加权算法**，为农户高效推荐合适的联合贷款人；对银行端智能匹配优质客户，实现农户、联合贷款人、投资方三方共赢。
3. **多方信息透明共享**：接入平台合作方的信息透明公开，商品供求两端同时展示，产销对接成功率更高。
4. **专家服务赋能生产**：农业知识库、在线问答、线下专家预约（出诊）三位一体，为农户提供从"种得好"到"卖得好"的全链条技术指导。
5. **技术架构现代化**：SpringBoot 3 + Vue 3 前后端分离 + JWT 无状态认证 + RBAC 权限模型，接口统一前缀与统一响应封装，易扩展、易维护、易部署。
6. **贴近真实业务闭环**：内置购物车、订单状态机（待付款→待发货→待收货→已收货）、站内消息通知、支付宝支付对接等完整电商能力，可直接作为课程设计 / 毕业设计 / 创业项目原型落地。

## 四、运行环境与版本要求

### 1. 后端环境

| 环境 / 组件 | 要求版本 | 说明 |
| ----------- | -------- | ---- |
| JDK | **17**（SpringBoot 3.x 最低要求） | 后端编译与运行 |
| Spring Boot | **3.2.5** | 后端主框架 |
| MySQL | **8.0+**（连接器 mysql-connector-j 8.0.33） | 数据库名 `rxt`，字符集 utf8mb4 |
| Redis | **5.0+** | 缓存 / 会话 |
| Maven | **3.8+** | 项目构建（内置 mvnw 包装器亦可） |
| MyBatis-Plus | **3.5.5**（spring-boot3-starter） | ORM 增强 |
| Spring Security | 随 SpringBoot 3.2.5 | 认证与 RBAC 鉴权 |
| JJWT | **0.11.5** | 无状态 Token 签发与校验 |
| fastjson | 1.2.83 | JSON 处理 |
| Alipay SDK | 内置 | 支付宝支付对接 |
| springdoc-openapi | 内置 | 接口文档（Swagger UI） |

### 2. 前端环境

| 环境 / 组件 | 要求版本 | 说明 |
| ----------- | -------- | ---- |
| Node.js | **18+**（建议 18.19 / 20.x LTS） | 前端构建环境 |
| Vue | **3.x** | 前端框架（组合式 API） |
| Vite | 5.x | 构建工具 |
| Element Plus | 2.x | UI 组件库 |
| Pinia / Vue Router | 2.x / 4.x | 状态管理 / 路由 |
| Axios | 1.x | HTTP 请求 |

### 3. 快速启动

```bash
# 1. 准备数据库：MySQL 8.0 中创建数据库 rxt（utf8mb4），导入建表 SQL
#    CREATE DATABASE rxt DEFAULT CHARACTER SET utf8mb4;

# 2. 修改后端配置 src/main/resources/application.yml
#    - spring.datasource.url / username / password
#    - spring.data.redis.host / port

# 3. 启动 Redis 后，运行后端（端口 9090）
mvn spring-boot:run
# 或使用包装器
./mvnw spring-boot:run

# 4. 前端项目安装依赖并启动
npm install
npm run dev
```

后端启动后访问接口文档：`http://localhost:9090/swagger-ui.html`（springdoc-openapi）。
